## 📌 Sobre a carreira

A carreira prepara para atuar no desenvolvimento back-end com Python, **dos fundamentos da programação até a construção de aplicações web, APIs, microsserviços e sistemas distribuídos**. A jornada é organizada em níveis, com cursos em ordem lógica e *checkpoints* práticos ao final de cada nível.

| Estrutura | Base + 3 níveis, com checkpoint ao fim de cada nível |
| Certificados | Por curso, por nível (exceto a Base) e na conclusão da carreira |

### O que a carreira cobre

- Fundamentos de programação, lógica e Python
- Construção de aplicações web e APIs (Django, FastAPI e Flask)
- Qualidade de código, testes e segurança
- Arquitetura de software, desempenho e escalabilidade
- CI/CD e deploy de sistemas em produção
- Microsserviços e sistemas distribuídos

## 📁 Organização do repositório

A cada curso estudado, o código e as anotações ficam em uma pasta própria, seguindo a ordem da carreira:

```text
alura-estudos-backend-python/
├── nivel-1-estruturando-aplicacoes-web/
├── nivel-2-qualidade-seguranca-escalabilidade/
├── nivel-3-arquitetura-desempenho-deploy/
└── README.md
```

Cada pasta de curso deve conter:

- o código desenvolvido durante as aulas;
- um `README.md` curto com o que foi aprendido e como rodar;
- desafios e exercícios extras, quando houver.

## ▶️ Como rodar os projetos

Cada curso tem as suas próprias dependências. Como regra geral:

```bash
# 1. Clone o repositório
git clone https://github.com/davi-carvalho-dev/alura-estudos-backend-python.git
cd alura-estudos-backend-python

# 2. Entre na pasta do curso desejado
cd 00-base/02-python-primeira-aplicacao

# 3. Crie e ative um ambiente virtual
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
.venv\Scripts\activate           # Windows

# 4. Instale as dependências (quando houver requirements.txt)
pip install -r requirements.txt
```
